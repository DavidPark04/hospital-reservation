# 프로젝트 계획서

기준일: 2026-11-20. [노션 수정안 v1.1](https://app.notion.com/p/879b8822a70f82f789298129ce73194d)과 [기술 설계](https://app.notion.com/p/a3cb8822a70f8369b3d401c2c8e32be5)를 참고한 저장소용 요약입니다. 원본은 검토안이며 구현 결과가 아닙니다.

## 목표와 범위

AI 상담 또는 직접 검색으로 병원을 찾고, 샘플 일정으로 모의 예약을 생성·변경·취소합니다. 실제 병원 접수, 진단·처방, 결제, 모바일 앱은 범위 밖입니다. 회원·권한, 병원 검색, 출처 표시, 예약 정합성, 관리자 일정을 먼저 완성합니다.

병원평가 정보·NMC 진료요일·상담 이력·이메일 알림은 필수 기능 검증 후 선택합니다. 영통구 MVP는 팀의 최종 범위 확정이 필요합니다.

## 역할과 결정

박다윗(DavidPark04)·김도형(kdh0381) 두 사람의 상세 FE/BE 담당은 미정입니다. Issue마다 담당자 1명과 상대 리뷰어를 정합니다. API·DB 변경은 양쪽이 확인합니다.

착수 시 확인: 영통구 범위, 라이브러리 버전, 공공 API 승인 상태, Render 도입·비용, 정기 회의 시간, 공식 제출일·제출 방식.

## 자료의 적용 우선순위

현재 요청과 팀이 확정한 최신 노션 결정 → 저장소 설계 문서 → 이전 기획서 순서로 확인합니다. 상충하는 변경은 Issue에 근거를 적고 코드와 문서를 함께 수정합니다. MySQL·JPA·RDS·Flyway 및 Discord·Figma 필수 사용은 v1.1에서 대체되었습니다.
