# 저장소 설정 현황

설정 준비 중입니다. 원격 생성·검증 결과로 이 문서를 갱신합니다.

목표: `main` 기본 브랜치, `main`·`develop` PR 필수, 상대 승인 1명, 새 변경 시 승인 초기화, 대화 해결, `Repository checks` 성공, force push·삭제 금지.

GitHub 요금제·권한에 따라 보호 설정 사용 가능 여부가 달라집니다. 파일과 규칙 문서가 있다는 것만으로 서버에서 강제되는 것은 아닙니다. [GitHub 보호 브랜치 안내](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches)
