# 시연 시나리오 초안

구현 완료 후 검증된 동작으로 갱신합니다. 실제 사용자 데이터 대신 가상 계정·샘플 일정을 사용합니다.

1. 서비스 목적과 모의 예약임을 설명합니다.
2. 직접 검색으로 지역·진료과를 선택하고 실제 자료의 출처를 확인합니다.
3. AI 상담으로 조건을 정리하고, 조회된 병원 후보와 근거를 확인합니다.
4. 샘플 의료진·일정 선택 → 로그인 → 최종 확인 → 모의 예약을 진행합니다.
5. 내 예약 조회·변경·취소와 관리자 일정 관리를 보여 줍니다.
6. 예약 동시 요청·중복 요청·타인 예약 접근에 대한 테스트 결과를 제시합니다.
7. 구현 범위와 미완료·선택 기능을 구분해 마무리합니다.
