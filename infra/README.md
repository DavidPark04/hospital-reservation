# 배포와 운영

현재 배포 설정·서비스·유료 리소스는 생성되지 않았습니다.

기획 기준은 Vercel 프론트엔드, MongoDB Atlas이며, Spring Boot 서버는 Render를 후보로 검토합니다. 도입 결정·요금·절전·시작 지연 확인 후 설정 파일을 추가합니다.

배포 PR에는 실제 빌드·실행 명령, 공개 URL, 환경변수 이름, CORS origin, FE SPA rewrite, DB 접근 범위, 헬스체크, 되돌리기 절차를 기록합니다. 비밀 값은 기록하지 않습니다.

BE·FE 테스트·빌드 성공 후 배포하도록 연결하고 운영 배포는 `main`만 사용합니다. `develop`은 통합 검증용이며 배포 여부는 별도로 결정합니다.
